# AI、异步与数据基础设施

## 简历处理管线

1. 上传接口流式计算哈希，保存原文件与元数据，快速返回批次/任务 ID。
2. 先用本地 PDF/Word/文本抽取和 OCR 获得可审计文本；只有版式复杂、扫描质量差或字段置信度不足时使用多模态模型。
3. 解析、身份候选匹配、冲突检测、索引、向量化和评分异步执行；每步保存输入版本、状态、尝试次数和结果摘要。
4. 人工复核不阻断同批其他项目；错误项可单独重试、修正和继续。

原始文件以 MinIO/OSS 为事实源，MySQL 保存对象元数据和业务事实，Elasticsearch/OpenSearch 是可重建投影。业务代码只依赖 `ObjectStoragePort`、`SearchPort`、`ModelPort` 等语义接口，不依赖具体 SDK。

邮件采集只依赖 `MailIntakePort`，采用数据库多账号、IMAP+SSL、固定周期和 account/folder/UIDVALIDITY/lastUid 游标。账号首次启用只保存当前 `UIDVALIDITY + LASTUID` 零基线，不为旧 UID 创建 intake；之后游标只在确定、可恢复的结果与 Outbox 同一事务提交后推进。管理员创建、测试、激活和停用版本化主题/发件人/特殊来源规则，禁止源码硬编码；规则正常未命中保存 `SKIPPED`、不建人工任务，已命中后附件歧义或 AI 分类/解析失败创建共享人工任务，规则加载/判断技术失败不推进。JD/简历分类、简历字段抽取和证据生成由 AI 完成。Message-ID、来源键和附件流式哈希共同幂等；附件先进入隔离对象存储并通过 MIME/大小/数量/恶意文件检查。Boss 自动采集是尚未真实接入的 P0；无参数时适配器明确禁用但不阻塞开发。账号秘密使用受控 Secret/加密配置；当前不建设邮件字段脱敏或个人收件权限，但日志不得输出凭据、令牌、完整正文/附件载荷或模型密钥。外部参考只用于提炼运行方法、契约和测试样例，全部独立实现，不复制凭据实体、监听器或源码。

## 模型网关

- Spring AI 负责统一调用、多模态和供应商适配；轻量路由按用途、能力、启停、区域、预算和降级策略选择模型。
- 模型配置可管理，但 API Key/Base URL 只在受控管理边界使用并加密；普通 HR 不能绕过用途绑定指定生产密钥。
- 提示词把简历文本视为不可信数据，要求结构化 Schema 与证据定位；简历中的指令不得覆盖系统指令。
- 日志只记录 operationId、用途、供应商、模型、耗时、Token、请求 ID 和脱敏错误。完整简历、提示词和模型载荷日志默认关闭。
- 对输入、输出、累计文本、并发、Token、超时和成本设硬上限。结构修复最多按明确策略重试，失败保留可读草稿和证据，不伪造成功。
- 当前没有业务金标样本不阻塞 Schema、端口和解析切片；先使用合成/匿名边界样本验证结构、证据、越权字段、Prompt 注入和失败语义，后续样本形成后再追加数值质量基线。

## 任务、消息与 Outbox

- MySQL 事务同时写业务事实和 Outbox；发布器经 RabbitMQ Confirm/Return 后标记成功。消费者按 eventId + 业务幂等键去重。
- 任务状态至少区分 queued/running/succeeded/failed/cancelled；需要恢复时增加 claimed、lease、retryable、nextRetryAt 和 checkpoint。
- 状态机必须单调，进度不得倒退，迟到完成/失败事件不得覆盖较新终态。领取使用带前置状态的 CAS 更新，租约到期可安全回收。
- 重试使用有限次数、指数退避和抖动；不可重试失败进入死信/异常中心。重放前验证幂等与当前状态。
- API、Worker、Batch 独立线程池和连接池。AI/OCR 队列必须有限流、背压、队龄与积压监控，不能拖垮在线接口。
- 黑名单激活事件只驱动受影响流程查询投影和逐条人工处置任务；消费者不得批量生成 `REJECT/WITHDRAW` 或改写 Application/推荐终态。

## 搜索与性能

- 在线查询顺序：权限过滤 → BM25/结构化/可选向量召回 → Top K → MySQL 权限、公司黑名单和当前甲方限制事实回查 → 确定性重排。ES 风险投影只用于召回/提示；联系、新建 Application、客户推荐和流程推进命令必须在各自事务前通过 `talent.api` 强一致回查 MySQL 当前公司黑名单，不能依赖索引延迟或缓存绕过即时阻断。
- 索引带 schema/model 版本并用别名切换；变更经 Outbox 增量投影，提供按时间修复和全量重建。
- 禁止在在线请求中全量调用模型或深分页。全量任务使用 PIT/search_after、切片、断点续跑和可取消批次。
- 毫秒级目标只适用于在线检索与预计算结果读取；任何性能承诺必须有真实数据量、负载模型和 p95/p99 压测证据。
