# 月报参考模板

`reference-template.docx` 是用户提供参考稿的去数据版，仅保留页面、样式、编号、字体表与基础设置。无业务正文、图片、人员信息、作者元数据、外部关系。源参考 SHA-256：`897b4d48d69d144401fcf94d839f8de4f9dfe19810d522bd21f3390adf010540`。

- 页面：A4 11905×16838 twips；上/下1361、左/右1417；正文宽9071。
- 样式：`rdbvau` 标题（24pt）、`ablt93` 正文（11pt/1.3倍）、`7yyd7k` 一级（16pt）、`0qbh3o` 二级（14pt）、`ympv2x` 三级（12pt）。标题左对齐；Java为正文明确宋体/Times New Roman字体。
- `MonthlyReportDocxRenderer` 填入动态内容；规则表2列、部门表7列、重点发送人表5列。需求及完整发送人保留在附录。
- `MonthlyReportDashboardRenderer` 动态绘制4＋4＋2十图；字体来自相邻fonts资源。没有调用Agent/模型或运行时网络取图。
- 有意不复制参考稿的业务推断、错误比例比较、表格孤行和大段留白。不得用参考图像或静态数字替代真实月份数据。
- 修改模板时同时更新模板版本并用本地样例执行生成与原生Word分页检查；构建中的契约测试检查模板无正文/媒体/外部关系和核心页面约束。
