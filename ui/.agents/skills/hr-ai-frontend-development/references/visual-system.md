# HR 招聘工作台视觉系统

视觉方向是“可信招聘档案室”：白色数据面与浅蓝画布的高密度工作台，使用蓝色作为人工操作主色，靛蓝表示 AI/证据。背景允许低透明度的静态虚化色块，文字、控件和数据面保持清晰，不用大面积渐变或发光效果。

## 核心 Token

复用当前 [DESIGN.md](../../../../DESIGN.md) 的相关 Token 和 [global.css](../../../../src/styles/global.css) 中已实现的工作台变量；Ant Design 组件沿用应用 ConfigProvider。不要在本参考复制第二套色值，也不要因局部修改重建主题。产品语义与实现有实质分歧时仅核查受影响值。

- 基础圆角 8px，卡片 10px，弹层 12px；工作表面主要依赖 1px 边框，阴影只用于浮层。
- 紧凑模式行高 40–44px，控件 32–36px；正文不得低于 12px，主要业务正文使用 14px，标题 20–24px。
- 中文字体采用 `Inter, "Noto Sans SC", "PingFang SC", "Microsoft YaHei", system-ui, sans-serif`；数字和版本信息使用等宽数字特性，不另引入装饰字体。

## 页面骨架

- 导航名称、顺序和工作区归属以 [PRODUCT.md](../../../../PRODUCT.md) 的当前导航约定及对应实现为准，不保留另一套固定主域清单。局部控件修复不调整导航。
- 工作区沿用现有顶栏、密度和边距；全部功能在桌面及移动端导航可发现，不使用造成大块空白的居中窄容器。
- 页面头部包含标题、对象上下文、关键状态和 1 个主操作；次要操作进入相邻按钮或更多菜单，不铺满操作栏。
- 列表页采用 `标题/指标摘要 -> 搜索筛选 -> 批量动作 -> 表格/结果 -> 分页`；详情页采用 `上下文头 -> 主视图 + 业务侧栏 -> 历史/证据抽屉`。

## 标志性元素：证据轨

AI 面板左侧使用一条细证据轨，依次标出“事实来源—AI 判断—HR 决定”。四通道各有固定图标和文本标签；颜色仅作辅助。点击任一判断能定位原始简历页码/段落或 JD 条款。

证据轨只用于 AI 判断、冲突和风险，不装饰普通卡片。它让领导看到 AI 赋能，也让 HR 清楚系统没有替代最终决定。

## 禁止事项

- 不全局隐藏滚动条，不让整页承担表格/看板横向滚动。
- 不引入 Tailwind、shadcn、Next.js 布局或绕过主题的硬编码颜色。
- 不使用大面积紫蓝渐变、发光阴影、emoji 状态图标、无意义统计卡和装饰英文眉题。
- 不把每个区块都做成圆角卡片；同一数据面可用分区和细线建立层级。
- 风险、通过、未知均需图标/文字/说明，不能只靠红绿颜色。
