# VGO ATS 产品上下文

VGO ATS 是一套 AI 辅助招聘工作台，包含简历收件、结构化解析、JD 管理、匹配评分、招聘流程、面试日程、Offer 与入职和统计报表。AI 提供建议，HR 保留最终判断权。本文保留通用产品约束，不包含原公司的组织、实际业务资料或参数。

## 页面与导航

公开首页以“让人才与机会，在这里相遇”为主题，展示 VGO 品牌、人才连接插画及简历解析、智能匹配、招聘协同三项能力，并提供单一“登录工作台”入口；不再展示日历、日期、问候和每日语录。首页无需登录，工作台由现有认证与权限守卫保护。品牌采用 VGO 原创 SVG，见 [设计规范](DESIGN.md)。

工作台主导航包含招聘洞察、候选人库（按角色显示为团队候选人／我的候选人）、AI 评估、招募管道、面试日历、人才公海及录用交付。实际显示范围由已登录用户能力决定。设置包含 JD、公共 JD 内容库、解析校验、邮件收件、月度汇报及账号／部门管理。导航与授权以实现和[根目录共享文档](../docs/README.md)为准。

工作区设置不提供云存储管理页面或入口；文件存储仍由部署配置维护，继续服务简历附件、AI 归档与月报等业务。

## 通用行为

- 每批简历关联一个冻结 JD 版本，解析和默认评分完成后才进入可用简历列表；失败、身份冲突、重复和缺少 JD 的记录在解析校验中恢复。
- 候选人库仅保留待筛选列表。未处理的简历持续留在原归属人的待筛选中，不再按超时规则转入共享库；手动筛选结束转共享、推荐及历史招聘记录继续保留。旧待处置链接返回待筛选并保留个人池筛选和详情上下文。
- 默认评分与个人评分方案分别冻结。重新评分不覆盖历史结果，不自动替代 HR 筛选、推荐或招聘决定。公开默认参数为示例，由使用团队按需求维护。
- 招聘流程记录沟通、逐轮面试、客户推荐、录用、Offer 与实际入职；计划名额、Offer 进展和实际入职分别表达。
- 日程协同汇总真实预约与面试，可在当前页面查看详情、改期或取消，关闭后回到原上下文。
- 公共 JD 与共享简历必须遵守服务端的数据范围和操作权限；前端不能扩大授权。
- 统计来自接口，按用户授权和筛选范围计算。空值和未知值明确展示，不使用模拟数据补齐真实报表。地区分布按原始岗位工作地区标签排序，完整保留未知和多地点记录。

## 工程和体验约束

React 单页前端通过同源 `/api/v1` 访问根目录 Java/Spring 后端。开发代理默认为本机 `localhost:8080`，不预设公司服务器或真实账号。

账号新建和管理员重置后显示服务端返回的随机临时密码，可复制后安全交付；首次登录必须改密，确认关闭后不再显示临时密码。

列表与看板保持高信息密度，表格在自身区域滚动。关键操作提供可见键盘焦点和可读名称，状态不能仅依赖颜色。AI 判断同时展示维度原因、必要条件、附加项及信息不足状态。失败时保留已填写数据，并提供明确的恢复入口。

历史原型与测试夹具只能使用明确合成资料；截图、报告和本地生成证据不纳入发布文件。
