# Noto Sans SC

- 来源：[Google Fonts 官方字体仓库](https://github.com/google/fonts/tree/main/ofl/notosanssc)，许可证见同目录 `OFL.txt`。
- 网页分发版本：Google Fonts `v40`，于 2026-09-09 获取。
- 清单来源：`https://fonts.googleapis.com/css2?family=Noto+Sans+SC:wght@100..900&display=swap`（Chrome 浏览器响应）。
- 字体文件来自清单中的 `https://fonts.gstatic.com/s/notosanssc/v40/`；仅将 CSS 的资源地址改为同目录相对路径，未修改字体二进制或删减字符。
- 101 个 WOFF2 分片保留官方 unicode-range 和 100–900 可变字重，由浏览器按实际文字加载；网页运行时不请求外部字体服务。
- `font-display: swap` 保证加载期间文字可读；超出字库覆盖范围的姓名或符号使用系统回退字体。
